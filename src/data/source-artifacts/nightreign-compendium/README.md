# Nightreign Compendium Bundles

These are original built JavaScript artifacts from the downloaded compendium source.

Known useful files:

- `weapons-dSd6emJz.js`: weapon data and helper exports from the source app.
- `types-4NLhqcYa.js`: enum-like mappings and source utility exports.
- `AttackPowerTab-C00lmv-K.js`: attack power table and calculation UI logic.
- `AttackTypeIcon.vue_vue_type_script_setup_true_lang-D7LWPSpJ.js`: attack/status icon mapping reference.
- `CompendiumPage-CcsKEnDC.js` and `EffectSearch.vue_vue_type_script_setup_true_lang-ByaM8oqD.js`: compendium/search UI references.
- `index-*.js` and `styles-*.js`: source app support bundles.
