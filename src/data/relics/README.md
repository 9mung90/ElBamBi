# Relics Data

This folder keeps Nightreign relic-related data separated by source role.

- `raw/relics.json`: relic item records.
- `raw/effects.json`: relic and weapon effect records from the extracted source.
- `raw/effects-ko.json`: Korean relic and weapon effect descriptions.
- `raw/weapons.json`: weapon stat records keyed by weapon id.
- `raw/candidate-files.json`: source candidate file metadata.
- `index.ts`: typed exports for app code.
- `types.ts`: shared TypeScript shapes for these datasets.
