# Data Layout

- `ashes`: Ashes of War names, properties, descriptions, icons, and motion GIF URLs.
- `characters`: character stat data.
- `combat`: attack power calculation references and extracted snippets.
- `gestures`: gesture names, acquisition descriptions, and icons.
- `items`: miscellaneous item names, types, descriptions, ability text, and icons.
- `nightfarers`: Nightfarer descriptions, skills, equipment, and related image URLs.
- `relics`: relic items, effects, localized effect text, relic-linked weapon stats, and source candidate metadata.
- `source-artifacts`: downloaded built JavaScript bundles kept only for analysis and reverse reference.
- `spells`: sorcery/incantation names, schools, slots, requirements, descriptions, icons, and motion GIF URLs.
- `talismans`: talisman names, descriptions, ability text, and icons.
- `vessels`: vessel names, character links, relic slot color layouts, and image URLs.
- `weaponCatalog`: weapon catalog names, categories, descriptions, and image URLs.
